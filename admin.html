Aqui você gera a página individual de pagamento pra cada cliente. Como funciona: 1) o pedido chega no seu email pelo formulário de encomenda; 2) você cria um pedido aqui com os dados dele, sobe a foto do QR code (Pix ou o que você usar) e cola o link de pagamento; 3) clique em "Salvar este pedido" pra gerar o link da página; 4) copie o link (e baixe o QR se quiser anexar como imagem) e mande pro cliente por email ou WhatsApp junto com a confirmação do pedido. O link só passa a funcionar 1-2 minutos depois de salvar.

Como gerar sua chave (uma vez só)

  1. Vá em github.com/settings/tokens?type=beta (token "fine-grained")
  2. Clique em Generate new token
  3. Em "Repository access", escolha Only select repositories e selecione só o repositório do seu site
  4. Em "Permissions", procure Contents e mude de "No access" para Read and write
  5. Clique em Generate token lá embaixo
  6. Copie a chave gerada (começa com github_pat_...) e cole no campo acima — ela só aparece uma vez, se perder tem que gerar outra

Guarde essa chave como uma senha. Qualquer pessoa com ela consegue editar o site. Se desconfiar que ela vazou, volte nessa mesma página do GitHub e clique em "Delete" na chave — ela para de funcionar na hora.
